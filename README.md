# La Fortissima - Control de Turnos y Pagos

Aplicación web para la gestión de turnos de trabajo, cálculo automático de horas y control de cobros.

## Características

- ⏱️ **Registro simplificado de turnos**: Selecciona fecha, hora de inicio y hora de fin.
- 💶 **Cálculo automático**:
  - Horas totales calculadas al instante (incluyendo turnos que cruzan la medianoche).
  - Multiplicación automática por la tarifa de **8,00 €/hora**.
- 📊 **Resumen financiero mensual**:
  - Total Generado.
  - Nóminas recibidas ingresadas.
  - Efectivo / Adelantos a cuenta.
  - Restante pendiente de liquidar.
- 🎯 **Metas y Objetivos de ahorro**: Define tus objetivos personales y añade fondos conforme cobras turnos.
- 💾 **Copia de Seguridad**: Exportación e importación de datos en archivo JSON.
- 🌓 **Modo Oscuro / Modo Claro**.

## Instalación y Ejecución

```bash
npm install
npm run dev
```
